## Factory system for Transport Game Europe

My biggest priority, on paper, is finishing this system titled "[Factories](https://transportgame.eu/forum/t/63615d70-bc36-11f1-9554-bc241130ed3b)" for my live-game [Transport Game Europe](https://transportgame.eu).

It's going to be a system that players can interact with in the mid-game, where they'll be able to interact with factories, manage the input and output,
complete chains (wheat into flour into bread) and make some money while doing so. The initial version will be run by NPCs, but I have some ideas
that will allow players to create their own factories.

It's been a bit of a bigger update than I anticipated, but in hindsight that's what you get when you introduce a complete new 'system' to a game.

What I like to do is just start a bulletpoint list in Markdown and flesh out my ideas. Eventually there will be more lists, for units, for factories, then
whenever I run into an issue, another rule gets added to the first list. Eventually I'll start making database tables or JSON examples.

My next step is often just mocking up the page and seeing what information I need.

Surely I can get away with some hardcoded things, but alas, that's not my personality..

## Project Army Game

This idea is actually a Roblox game, turned into pen-and-paper play, turned into shoddy developer prototype.. 

My 9-year-old was creating a game on paper where you could pick a faction (US vs RU) and then use units to fight head-to-head, which he took from a Roblox game.
Encouraged by his enthusiasm when I said I could make this into a game, I started on a prototype.

It looked okay, but eventually I said "It's a lot of work, I'm not sure it's worth it". Then some days later I told myself
to just make something really small.

I got some help making a colour palette and suddenly, it kinda looked interesting. My initial idea was to use pixelart for the units,
but this was very difficult to find, nor was it uniform if I did. Also considering how many units I had already thought of during the prototype.

I settled for using regular images, dragging them through a picture to pixel filter and then using a CSS filter to make them a bit green.

for picking your units.
