(Spoiler: TLDR) 👆
A website that looks like a desktop, where you mostly see a browser, but there's also a floating div that acts as a chat app. People can use the 'in-game' browser to go to community related things, one of which is a fake domain registrar, where people can 'buy' a domainname and have it go to their profile page.

This idea actually came about roughly the same day I had my Zombie Town idea, but that was a bit more substaniated than this and had priority. However, with the same reasoning as that blogpost, I decided to write this one down as well. Because I kinda like the idea, but just don't have time for it now, but still want to archive the idea for later.

Background

So this thought-train left the station when my kid drew a computer-like system on paper and I needed to play with it. This got me thinking, it would be funny to mock this on an actual site. And then have an addressbar that doesn't connect to the internet, but only some kind of localnet or lore-net, if you will.

The idea..

So if the browser is fake, I can also fake domains, and then people can sign up for a 'lore'-domain and have it link to their profile page, which will have a guestbook and since everyone's already logged in, they can easily leave comments.

.. and if they log in to a fake computer system, there can also be a chat that looks like an app (maybe MSN Messenger? Or ICQ?) where they can add friends, join channels etc.

.. and maybe this fake computer also has a Fediverse/Twitter clone that people can use.

Forums, profile pages, chats and direct messages are not new to a community website, but packaged like a computer system would give it a spark. ✨

The name

I had no name for it yet, and also don't know which kind of community it would target, but I thought if I used a .cc domain it could be called Something something dot Computer Club.
